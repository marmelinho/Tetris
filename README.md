# Тетрис на C++

Реализация игры «Тетрис» с графическим интерфейсом 
в консоли на C++ с использованием принципов ООП и Windows API.

## Демонстрация 
![Меню](images\menu.png)
![Геймплей](images\gameplay.png)

## Стек
- С++
- ООП
- Windows API (графика)

## Что реализовано
- Игровое поле 17х10
- 7 фигур, повороты, коллизии
- Подсчет очков, изменение сложности

## Как запустить
1. Скомпилировать `tetris.cpp`
2. Запустить `tetris.exe`
